# ADR-0064: License ratified — Apache-2.0 (Phase A)

Status: accepted (v0.3 Phase A). Date: 2026-10-06.
Supersedes: ADR-0008 (deferred evaluation → ratified).

## Context

ADR-0008 evaluated options and provisionally recommended
Apache-2.0 but deferred ratification, leaving the tree
all-rights-reserved with no LICENSE file. The v0.2.0 audit
(P0-1) found this blocks any honest "open-source" claim,
contribution, and redistribution. v0.3 Phase A audited
every source file, script, fixture generator, doc, and
asset for third-party restrictions before choosing.

## Decision

- **Apache-2.0** for all project-authored files (code,
  scripts, docs, fixtures). `LICENSE` at tree root carries
  the full text; copyright line names the repository owner
  account (`MohamedLahmeri01`, flagged change-on-request).
- Third-party audit result (2026-10-06): **nothing to
  except.** No vendored dependencies, no copied-in code
  (zero copyright/license headers found tree-wide outside
  this decision), no redistributed fonts (GUI glyphs are
  read from VGA BIOS hardware at runtime, never shipped),
  fixtures generated by project scripts, toolchain and
  hypervisor pre-existing host tools. No NOTICE file
  needed (nothing to attribute).
- Per-file headers: NOT added (110+ files, no enforcement
  tooling yet; root LICENSE governs — revisit with lint
  tooling in Phase F). No third-party notices existed to
  modify; none were touched.

## Evidence

Repo-wide grep for copyright/license/BSD/MIT/GPL/vendor
strings (only hits: ADR-0008, README's honest
all-rights-reserved notice, false-positive RLIMIT);
`.rs`/vendored-dir inventory empty; dist manifest review.

## Hard lessons

- A "provisional recommendation" with a sign-off gate and
  no owner of the gate rots into permanent deferral:
  ADR-0008 waited from Phase 0 to v0.3. Gates need owners
  and deadlines, not just conditions.

## Consequences

- Tree is Apache-2.0 from this commit; README, dist, and
  T18 updated in the same step. Contributions fall under
  §5 (inbound = outbound) without extra paperwork.
- Docs/fonts licensing (CC-BY-4.0 candidate in ADR-0008)
  folded in: same license, no split (simpler; revisit if
  assets ever need it).
