# ADR-0023: EXT4 read-only on a third disk

Status: accepted (Phase 7e). Date: 2026-10-03.

## Context

Two filesystems live (RAMFS volatile, FAT32 with 8.3 case-folding).
A second on-disk format proves the VFS graft is format-agnostic and
teaches the real-world case-sensitive, inode-based layout. EXT4
read-only on a third disk (secondary master) is the honest slice:
no journal replay, no extents, no writes.

## Decision

ATA driver grows channel-relative ports (drives 2/3 = secondary
master/slave; IRQ15 already masked with 14). `tools/mkext4.py` builds
a byte-deterministic single-group image (4KB blocks, 128B inodes,
classic indirect only, no journal/extents: /HELLO.TXT 16B +
/DOCS/NOTE.TXT 15B, lowercase names); attached at IDE P1D0.
`kernel/fs/ext4.c`: parsed superblock + group descriptor (magic,
4KB, single-group, 128B inodes enforced), inode/directory/block
walks with step caps and rec_len progress checks, exact (case-
sensitive) matching, dot paths, direct + single-indirect data.
Grafted at /ext (placeholder dir, open-RDONLY materialize, readdir;
writes/mkdir are EROFS). Guest `EXT-OK`; host T11 vs the real image
+ 20000-name fuzz.

## Evidence

Guest `EXT-OK` (contract asserts on generated bytes); typed
`ls /ext` -> HELLO.TXT/DOCS, `cat /ext/hello.txt` -> ENOENT
(case-sensitivity, correct), `cat /ext/HELLO.TXT` (via Shift
scancodes) -> `hello from ext4`; `nova test` 11/11.

## Hard lessons

- Count string bytes mechanically (again): "ext4 nested ok\n" is 15,
  not 16 (seed-length class of bug, same as 7a).
- ext split_parent missed the leading-slash skip (first component
  always empty -> EINVAL everywhere): the FAT twin had it; shared
  helpers would have prevented the divergence.
- Stale `size`/`is_dir` across reused test locals masks the real rc:
  the debug probe (fresh 0xDEAD/7 sentinels) found it in one run.
- Lowercase shell input on a case-sensitive FS is user error, not an
  OS bug: verify with Shift scancodes (0x2A down ... 0xAA up).

## Consequences

- Read-only (EROFS), single group, no extents/journal/symlinks.
  Multi-group + extents + write path stay future work.
- Next: NOVA-FS design note; then Phase 8 drivers (DMA/IRQ disk I/O
  replaces polling on all three disks).
