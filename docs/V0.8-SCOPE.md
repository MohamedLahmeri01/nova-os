# NOVA OS v0.8 — Scope (prototype milestone)

## Primary capability

**Reboot-persistent user files on graft volumes.**
`put /disk/<name> <text>` and `put /nova/<name>
<text>` write through to the attached FAT32 and
NOVA-FS disk images; `cat` reads them back;
`rm` deletes them; `ls /disk` lists them; and
bytes survive a genuine poweroff + cold boot
(proven in the demo, screenshot record).

## Acceptance criteria (all met)

1. Lifecycle battery `PERSIST-OK` green every boot
   (create/write/grow/reread/delete/gone on both
   volumes, byte-exact, NOVA fsck-clean after).
2. Reboot demo: write → poweroff → cold boot →
   read back identical (screenshots v8_demo1–3).
3. Full suite 23/23 ×3 + gate (no regressions).
4. Durability contract documented (below), with
   crash-consistency explicitly NOT claimed.

## Supported environment

VirtualBox 7.2.6, `NOVA-OS-CONSTRAINED` (2 CPU /
1024 MB), IDE disks (`fat32.vdi` = FAT /disk,
`nova.vdi` = NOVA-FS /nova), NAT virtio-net.
Disposable VDIs; never the host disk.

## Durability contract (read carefully)

- Survives: clean poweroff/reboot (VM reset or
  poweroff), normal shell close/delete cycles.
- Each `put`/write completes synchronously to the
  virtual platter before the command returns
  (no write-back cache to lose: single-entry read
  cache invalidated on write; NOVA-FS checkpoints
  synchronously).
- NOT claimed: crash-consistency under mid-write
  power loss (no journaling proof on FAT; NOVA-FS
  journal exists but its recovery path is not
  power-cut tested), wear-leveling, encryption,
  multi-GB files (64 KB cap per file), concurrent
  writers from two VMs sharing one VDI (never do
  this), or fsck repair (audit only).
- Boot selftests rewrite fixed scratch files
  (`/W.TXT`, `/BIG.BIN`, `/NOVA-P.TST` cycle)
  on the same volumes — user files are untouched,
  but the volumes are test fixtures, not archival
  storage. Back up anything you care about from
  the host side (copy the .vdi while powered off).

## Unsupported (unchanged from beta)

SMP, TCP/TLS/crypto/OTA/secure boot, USB, ARM64,
Linux ABI, pipes/shm/signals/mmap, mouse,
history/completion, power-loss testing, formal
proofs, production use of any kind.

## Baseline preserved

v0.5 (`59ea07b`) history intact; all beta behavior
(console, 37 shell entries, `!!`, uptime/about,
exit guidance, fault/panic path) re-verified
green in this campaign.
